# speices_configs of MMAseq for uGerm
This repository aims at containing the species_configs for MMAseq, as required to be hosted on ugerm.

To implement these configs for uGerm, assuming that `mmadeploy` have been executed with `deploy_dir` set to `/Path/2/deploy/` follow these instructions:
```
git clone https://github.com/ssi-dk/species_configs.git /Path/2/deploy/
# Run MMAseq with the --custom flag
mmaseq ... --custom
```
